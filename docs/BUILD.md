# SLIN Build

SLIN is a Windows-first PowerShell application architecture, with a portable core intended to be paired with a native macOS runtime with a portable repository layout.

## Run

Use SLIN.cmd for commands. Use SLIN.ps1 chat for the conversational interface.

The repository is the source of truth. The same memory, cognition, diagnostics, learning, and security data model is intended to be shared across Windows and macOS runtimes.

## Scope

SLIN is modular and local-first. It does not claim to be an autonomous general intelligence; SLIN does not require an external AI provider.
