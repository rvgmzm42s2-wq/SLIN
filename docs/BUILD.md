# SLIN Build

SLIN is a Windows-first PowerShell application architecture with a portable repository layout.

## Run

Use SLIN.cmd for commands. Use SLIN.ps1 chat for the conversational interface.

The repository is the source of truth. A future desktop UI can wrap the same core without changing memory, cognition, diagnostics, or security modules.

## Scope

SLIN is modular and local-first. It does not claim to be an autonomous general intelligence; model inference can be attached as a separate local provider later.
